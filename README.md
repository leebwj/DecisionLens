# Decision Lens

A tool for understanding why something in a game scene behaved the way it did. Select an object to see what it considered and why it made its choice, then try a "what if" change and compare the result with the original.

CIS 4120 final project, Fall 2026.

## Setup

1. Install Unity 6000.3.23f1 from Unity Hub.
2. Add this folder as a project in Unity Hub and open it.
3. Open `Assets/Scenes/Main.unity`.
